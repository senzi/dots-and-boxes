# 安全前沿探索方向（safe-frontier）

目标：让 L4 拿到安全前沿局面就能**直接判断输赢与预期比分**，并评估这条路线的可行性。

## 三个探索点

1. **安全前沿生成器评估**（`tools/frontier-distribution.cjs`）
   - 生成器（`src/frontier.js`）产出局面的边数分布、完成格占比
   - 单局面存储空间（mask 142bit / base36 码 / 边索引）
   - 8×8 穷举安全前沿的搜索空间数量级估计

2. **快速预测算法**（`src/outcome.js` + `tools/fast-predict.cjs`）
   - 给定安全前沿 + 主视角（第一个开块的人），按价值块序列 + 换权 DP
     直接算胜负与预期比分（不模拟对局，~100ms 级）

3. **预测 vs 实际自战**（`scripts/predict-vs-selfplay.mjs`，主项目）
   - 同一安全前沿局面：快速预测的比分 vs 主项目 L4 双席位实际打完的比分
   - 统计胜负一致性、比分误差分布

## 关键语义

- 安全前沿 = 无安全边、无吃格的极大安全局面（`Frontier.generate(seed)` 产出）
- 主视角 = 安全前沿局面第一个开块的人（**无主动权方**——用户定义：开块瞬间即无主动权）
- 快速预测的 firstPlayer = **主动权方**（吃块决策者）= 1 − 主视角
- 快速预测假设双方都按 DP 最优博弈；实际自战双方用主项目 L4 策略——
  差异即"理论最优 vs 实际策略"的偏差

## 探索结果（2026-08-02）

### 1. 生成器评估（2000 个随机前沿，8×8）
- 已填边 65~76，中位 71，平均 70.6（剩余 66~77 边）
- **完成格 0**（安全阶段不产生已得分格 → 比分恒从 0:0 开始）
- 存储：mask 17.8B / base36 ~28 字符 / 边索引 ~71B；100 万前沿 ≈ 17MB
- 穷举空间 ≥1e20 量级 → **不可查表穷举**，必须价值块分解 + DP

### 2. 快速预测（outcome.js）
- 单局面 ~90ms：价值序列 + 换权序列 + 预期比分 + 胜负
- 例（1s9cwv）：14 块，价值 `1,1,1,1,4,4,4,5,6,6,8,8,10,4`，换权 `F,F,F,F,4,2,4,2,4,4,4,4,2,E`

### 3. 预测 vs 实际自战（50 个前沿，主视角先开，双方 L4）
- **胜负一致率 74%**（firstPlayer 修正前仅 26%——初版误把开块方当 DP 控制方）
- **比分差中位 0**：约一半局面预测与实战精确一致
- 差异局面（如 38:25 vs 22:41）：L4 实战偏离 DP 最优（L4 非完美博弈者），
  或复杂块的 DP 近似误差 → 即 L4 的改进空间
- 结论：快速预测可作 L4 的"理论天花板"参照，预测−实战差异 = 可优化量
