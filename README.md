# Dots and Boxes 63

点点连线（Dots and Boxes）经典方格游戏—— 围格子、吃连线，看谁圈地最多。

支持 6×6 / 8×8 / 10×10 三种棋盘、本地双人对战与 AI 对战，四档 AI 从休闲到宗师任你挑战。

## 玩法

轮流在点阵之间连线，谁连出最后一个边围成一个格子，格子就归谁，并**可以继续连下一笔**。一局结束看谁围的格子多。

- 棋盘由 `grid × grid` 方格构成，左上角点被移除，实际可得分格子为 `grid × grid − 1`（63 / 35 / 99 格）
- 一子围成格子后可连续行动，围得越多越赚

## 游戏模式

| 模式 | 说明 |
|------|------|
| 面对面 | 本地双人轮流操作 |
| 人机对战 | 与 AI 对战，可选四档难度 |

## AI 对手

| 难度 | 名字 | 战力 |
|------|------|------|
| L1 | 新兵 | 初出茅庐，落子随缘，偶尔上头 |
| L2 | 老兵 | 身经百战，会吃格、懂避坑，稳扎稳打 |
| L3 | 王牌 | 端局 Loony + 主动权控制，沙场老将 |
| L4 | 疯狂的算师 | 价值块全局演算，算尽终盘每一子 |

> 10×10 棋盘较大，AI 思考较慢，一局耗时较久。

## 功能

- **三种棋盘尺寸**：6×6（35 格）/ 8×8（63 格）/ 10×10（99 格），默认小尺寸
- **对局快照**：中途退出自动保存，刷新/返回主页可继续或放弃
- **历史回放**：最近对局列表 + 终盘棋盘回看（含 AI 命名与棋盘大小）
- **SVG favicon**、移动端适配、键盘/触摸友好

## 技术栈

- Vite + Vue 3 + Pinia + Vue Router
- 纯 JavaScript 规则引擎（无外部依赖）
- 三档基础 AI + 基于价值块分析的 L4 宗师（含独立研究实验室 `ai-research/`）

## 开发

```bash
npm install
npm run dev       # 本地开发
npm run build     # 生产构建（输出 dist/）
npm run preview   # 预览构建产物
```

### 测试

```bash
npm run test:engine    # 引擎 + AI 结构断言（34 项）
npm run test:l3        # L3 大师契约（21 项）
npm run benchmark:l3   # L3 vs L2 基准（20 局）
npm run benchmark:l4   # L4 vs L3 基准（20 局）
npm run selfplay:l4    # L4 自战（10 局）
```

## 部署

静态站点，构建产物输出 `dist/`，可直接部署到任意静态托管（如 Cloudflare Pages）。
