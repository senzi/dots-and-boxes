# L4 实战算法（疯狂的算师）—— 2026-08-02 基线副本

> 本文件记录 L4 实战算法的**当前实现**，作为基线副本（预测算法见 `AI-L4-PREDICTION.md`）。
> L4 = 安全前沿价值块估算 + 终盘预测（DP）+ 跨步计划执行；已参数化支持 6×6/8×8/10×10。

## 决策流程（`aiMoveLevel4`）

按优先级：

### 1. 吃格阶段（有可吃格、无安全边）
- 有安全边：`chooseCapture` 先拿免费分。
- 有 `l4Plans` 计划（本块开块时预测存入）：
  - **保权**（choice 含"保权"）：L3 严格 handout 计划 `bestControlPlanFull`（控制方吃 controlTake、让 handout）；失败回退 `handoutMoves` 最小让块。
  - **翻转**（choice 含"翻转"）：`chooseCapture` 吃光当前块。
- **无计划（接块局面，对手开块后轮到 L4 吃格）**：纯价值判断 —— `handoutMoves` 能标准让块就保权，否则吃光（不依赖 L3 策略函数）。

### 2. 安全阶段（有安全边）
`chooseStrategicSafe`：绝不主动制造三边格（同 L3）。

### 3. 安全前沿（无安全边、无吃格）
- `l4Opening(state)`：价值块分解（试下取最小）→ 开**最小价值块**的第一条等价开边（稳定选择，edge 字典序）。
- `l4Predict(state, 1 − player)`：全局终盘预测（主动权方 = 1 − player 视角）→ **本块保权/翻转计划**存入 `l4Plans`。
- 失败/无候选 → 最小回退（组件排序，实测 0 触发，仅防异常）。

## 跨步计划缓存（`l4Plans`）

- `WeakMap<state 对象, { controlCode, choice, handoutEdge }>`——key 为游戏层 state 对象（落子原地修改，引用稳定）。
- 开块时一次预测确定本块决策；吃格阶段按计划执行。
- 仅 L4 自己开块时写入；对手开块（L4 接块）无计划 → 走"纯价值判断"分支。

## 关键约束（用户拍板）

- **主动权方 = 吃块决策者**（能吃格时选择留 2/4 的一方）；开块方无主动权。
- **价值优先排序**：让 2/4 多少不参与排序；"试下" = 不同开边之间取最小机械闭包（吃边顺序分支不做最小化）。
- **反对连通域推理**（L5 初版误用已被指出并弃用）。
- L4 确定性：同局面同决策。

## 执行层与预测的对齐（重要）

- L4 执行（`bestControlPlanFull`/`handoutMoves`）与预测（`findStandardHandout`）的让块判定**在 DP 自选层面一致**（100% 对齐验证）。
- **规则（强制保权）不可接入**：强制"DP 自选翻转"的块保权 → 执行层找不到让法 → 强制落空。教训：预测只反映"L4 真能执行的决策"。
