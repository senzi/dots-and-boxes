# L4 预测算法（终盘预测 DP）—— 2026-08-02 基线副本

> 本文件记录 L4 预测算法的**当前实现与全部关键修正**，作为基线副本。
> 后续改动对照此文档：改动前先读，改动后同步更新。

## 定位

预测算法 = 给一个**安全前沿局面**，快速判断"双方都按 L4 策略打到底的比分与胜负"。
**已验证：预测 = L4 实际（100% 一致，比分差均值 0）**——因为 L4 本身就是该模型的最优执行者。

## 输入 / 输出

- 输入：安全前沿 mask + `firstPlayer`（主动权方，吃块决策者，0/1）
- 输出：`score`（恒为 [玩家0, 玩家1]）、`winner`、`blocks`（每块分解）、`tree`（每块最优决策链）

## 核心步骤

### 1. 价值块分解（`enumerateValueBlocks`）
安全前沿 → 逐块分解：极大安全前沿的等价开边 → 机械闭包取格子集合 → 等价开边合并 → 值从小到大消解（1→2→4→…）。
每块产出：`value`（格子数）、`boxes`、`controlCode`、`controlTake`、`handout`、`handoutEdge`。

控制事件类型：
- `FORCED_FLIP`（值 1）：无选择，吃光翻转
- `CHALLENGE_2`（值 2 争权）：吃 2 翻转 / 让 2 保权
- `KEEP_BY_2` / `KEEP_BY_4`：保权（吃 controlTake 让 handout）/ 全吃翻转
- `TAKE_ALL`：吃光翻转
- `GAME_END`：终局块，吃光结束（不产生控制事件）

### 2. 标准让块搜索（`findStandardHandout`）
保权的前提：找"标准让块边"（放一条边让对手闭包恰好吃 2/4 的连通块）。节点上限 30000，超限 `handoutEdge = null`。

### 3. 换权 DP（`solve`）
从后向前：控制方 c 在每块选**保权**（take=controlTake、give=handout、next=c）/ **翻转**（take=value、give=0、next=1−c），最大化自己总收益。
GAME_END：take=value、next=c（终局块归控制方吃）。

## 关键修正（2026-08-02 实测）

### 修正 1：保权前提 = 标准让块边（handoutEdge 非 null）
- **根因**：`handoutEdge = null` 的块（CHALLENGE_2 让 2、KEEP_BY_4 田字让 4）是**开边直接让**（没有单独放一条"让块边"）——实际 `l3ControlAfterMove` 判定非 handout 边 → **控制权翻转**；旧 DP 假设"让 = 保权" → 控制权流向分叉 → 终局块归属反了。
- **修正**：`optionSet` 中 KEEP/CHALLENGE 的"保权"选项仅当 `handoutEdge !== null` 时 `next = c`（保权），否则 `next = 1−c`（实际翻转）。
- **效果**：预测 vs L4 实际 74% → **100%**。

### 修正 2：firstPlayer = 主动权方（不是开块方）
- 用户定义：开块方无主动权（开块瞬间即无）。
- 主视角（玩家 0）先开块 → 主动权方 = 玩家 1 → `outcome(mask, 1)`。
- 误用开块方当 firstPlayer：一致率 26% → 修正后 74%（再经修正 1 到 100%）。

## 性能

~100ms/局（8×8）；块级 DP（不是边级搜索），随棋盘 6×6/8×8/10×10 多项式增长（10×10 约 4.3s 整局，比 L3 快 10 倍）。

## 验证记录

| 项 | 结果 |

| 预测 vs L4 自战（10000 局） | **100% 一致**，比分差均值 0 |

## 探索结论（不再入预测核心）

- **规则（强制保权）死结**：规则强制"DP 自选翻转"的块保权 → L4 执行层（handoutMoves）找不到让法 → 强制落空。**预测（DP 自选）的保权块 L4 全部能执行**（0 样本验证）——"预测说能保权但 L4 找不到"不存在。
- **保权 vs 翻转**：seed 1002 块 J 枚举 8 种组合 → J 翻转严格占优（40:23 vs 23:40）——DP 最优。
- **"拿到权不放手"（L5/keep 策略）**：100 局 13 胜 87 负——保权=每块让 handout，无条件保权=每块送分。
- **悲观修正**：DP 比分本身 100% 准确（预测净胜 >0 → 100% 赢），悲观打折有害（误杀 148 个必胜局）。
