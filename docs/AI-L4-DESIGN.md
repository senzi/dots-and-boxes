# L4 宗师 AI 设计（2026-08-01）

基于 L3（大师），安全前沿局面引入**价值块估算 + 终盘预测**（ai-research 固化算法移植）。

## 核心思想

> 到了安全前沿局面，每一步都做价值估算，决定**开什么、留不留、保不保权**。

**主动权定义（用户拍板）**：主动权方 = 能吃格时选择留 2/4 的一方（吃块决策者）。**开块方没有主动权**——开块的瞬间主动权已转给对手。

## 流程

1. **安全阶段**（有安全边）：同 L3，免费铺边，不制造三边格。
2. **安全前沿**（无安全边、无吃格）：
   - `l4Opening`：价值块分解（试下取最小）→ 开**最小价值块**的第一条等价开边
   - `l4Predict(state, 1-player)`：全局终盘预测（主动权方视角 = 1-player），确定本块**保权（留 handout）还是翻转（吃光）**，存入 `l4Plans`（WeakMap，key = 游戏层 state 对象，跨步生效）
3. **吃格阶段**（有可吃格、无安全边）：
   - 按 `l4Plans` 计划执行：
     - **保权**（`保权·让2/让4`）：L3 严格 handout 计划（控制方吃 controlTake、让 handout）
     - **翻转**（`全吃·翻转`/`吃2·翻转`/`吃光·翻转`）：吃光当前块
   - 无计划时回退 L3。

## 模块

- `src/engine/l4/l4-board.js`：参数化缺角棋盘（getBoard(N)，BigInt mask，移植 ai-research，支持 6×6/8×8/10×10）
- `src/engine/l4/l4-value.js`：价值块算法（机械闭包 + 标准让块 + 控制事件）
- `src/engine/l4/l4-outcome.js`：终盘预测 DP（每块保权/翻转最优）
- `src/engine/l4/l4-bridge.js`：主项目 state ↔ mask 转换 + `l4Opening`/`l4Predict`

## 关键决策

- **主动权方 = 吃块方**（用户澄清）：预测 firstPlayer 用 1-player（安全前沿轮到的是开块方）。
- **跨步计划**：开块时一次预测，吃格阶段按计划执行（避免每步重复分解，且 captures 局面有可吃边无法直接分解）。
- **确定性**：L4 同局面同决策（大师级稳定性）。
